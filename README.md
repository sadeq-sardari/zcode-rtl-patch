# zcode-rtl-patch

وصلهٔ جهت‌دهی خودکار راست‌به‌چپ/چپ‌به‌راست برای پیام‌های چت [ZCode](https://zcode.io) (اپ الکترونیکی).

مشکل: پیام‌های فارسی در چت ZCode چپ‌چین و با چیدمان اشتباه bidi نمایش داده می‌شدند. این وصله جهت هر بلاک (پاراگراف، لیست، تیتر، سلول جدول و…) را به‌صورت خودکار از محتوای همان بلاک تشخیص می‌دهد — فارسی را راست‌چین و انگلیسی را چپ‌چین می‌کند، حتی وقتی در یک پیام مخلوط باشند.

## استفاده

```bash
zcode-rtl-patch              # پچ نسخهٔ نصب‌شده (بعد از هر آپدیت فقط همین را بزنید)
zcode-rtl-patch --restore    # بازگردانی آخرین بکاپ
```

نصب اسکریپت:

```bash
cp zcode-rtl-patch ~/.local/bin/
```

پیش‌نیازها: `node`/`npx`، `python3`، `sudo` (فقط برای بکاپ و نصب نهایی — اسکریپت خودش درخواست می‌دهد).

بعد از پچ، ZCode را کاملاً ببندید (از system tray هم) و دوباره باز کنید.

## چه کاری انجام می‌دهد

1. آرشیو `/opt/ZCode/resources/app.asar` را به یک پوشهٔ موقت استخراج می‌کند.
2. یک اسکریپت خودکفا را در `out/renderer/index.html` تزریق می‌کند (قبل از `</body>`).
3. دوباره بسته‌بندی می‌کند، تعداد فایل‌ها را با نسخهٔ اصلی مقایسه می‌کند (در صورت مغایرت نصب لغو می‌شود).
4. بکاپ تاریخ‌دار می‌گیرد (`app.asar.bak.YYYYMMDD-HHMMSS` — هرگز بازنویسی نمی‌شود) و نسخهٔ پچ‌شده را نصب می‌کند.

## منطق تشخیص جهت

Classifier از پروژهٔ vte-rtl-heuristic (پچ RTL برای VTE/گنوم‌ترمینال) به جاوااسکریپت پورت شده است:

- **رأی‌گیری توکنی**: هر کلمه (جداشده با فاصله) به اکثریت حروف «قوی»اش رأی می‌دهد؛ پس شناسهٔ بلندی مثل `product_ledger_events` فقط یک رأی دارد، نه بیست حرف.
- **آستانه‌ها**: نسبت ۰٫۵۵ (حرفی یا توکنی)، کف سه توکن فارسی، حداقل ۲ حرف قوی.
- **اعداد و علائم خنثی‌اند**: «2026 این تصمیم اعمال می‌شود» RTL می‌شود؛ «۱۲۳۴۵» خنثی.
- **ارث‌بری**: بلاک بدون حرف قوی (مثل «1920×1080» یا «...») جهت را از بلاک مجاور می‌گیرد.
- **حالت مبهم**: به `unicode-bidi: plaintext` واگذار می‌شود (تصمیم با اولین حرف قوی — رفتار بومی مرورگر).
- **ایزوله‌کردن توکن‌های فنی**: `code`، لینک و `kbd` داخل‌خطی isolate می‌شوند تا ویرگول/پرانتز دورشان در جریان فارسی جا نپرد (معادل HTML همان shield پروژهٔ ترمینال).

## چرا در برابر آپدیت‌های برنامه مقاوم است

- **فقط یک فایل ویرایش می‌شود**: `index.html` رندرر (مسیرش با جستجو پیدا می‌شود، نه هاردکد).
- **CSS در زمان اجرا تزریق می‌شود**: هیچ وابستگی به نام فایل‌های هش‌دار (`styles-*.css`) نیست.
- **سه قلاب مستقل برای پیدا‌کردن بدنهٔ پیام**:
  1. بالارفتن از تگ‌های `data-streamdown` (امضای کتابخانهٔ streamdown که رندرر مارک‌دان چت است)؛
  2. کلاس امضای کانتینر `MessageResponse` (heuristic)؛
  3. کلاس `.prose` (یادداشت انتشار، ویکی).
  اگر نسخهٔ بعدی یکی را عوض کند، بقیه سر جایشان هستند.
- **تشخیص پچ‌شده**: اجرای دوباره بدون هیچ تغییری خارج می‌شود.

## تست‌ها

- اجرای کامل روی کپی اورجینال آرشیو: استخراج → تزریق → بسته‌بندی، با تأیید یکسان‌بودن ۲۸٬۵۱۳ فایل.
- صحت نحوی پیلود با `node --check`.
- تست رفتاری در کروم headless با DOM شبیه‌سازیدهٔ چت: پیام فارسی/انگلیسی/ترکیبی، پیام فقط-پاراگرافی (بدون تگ)، لیست‌ها، ارث‌بری بلاک خنثی، ایزوله‌شدن کد داخل‌خطی، و قواعد CSS — همه پاس.
- idempotency: اجرای دوم تشخیص می‌دهد و کاری نمی‌کند.

## محدودیت‌ها

- آپدیت خودکار برنامه وصله را پاک می‌کند — فقط `zcode-rtl-patch` را دوباره اجرا کنید.
- مسیر نصب پیش‌فرض `/opt/ZCode/resources/app.asar` است؛ می‌توانید مسیر دلخواه را به‌عنوان آرگومان بدهید (آرشیو و `app.asar.unpacked` کنارش لازم است).
- خروجی پنجره‌های ترمینال/ابزار عمداً LTR می‌مانند و `pre`/`code` دست نمی‌خورند.
